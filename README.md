# 📊 Customer Retention & Churn Analysis Dashboard

## 📌 Project Overview
This project analyzes customer churn patterns, retention drivers, and lifetime trends for a subscription-based business using Power BI.

## 🎯 Objectives
- Identify churn patterns
- Analyze customer segments
- Understand retention behavior
- Provide actionable insights

## 📊 Dashboard Features
- KPI Cards (Total Customers, Churn Rate, Avg Lifetime)
- Churn Trend Over Time
- Customer Distribution (Active vs Churn)
- Churn by Plan & Segment
- Interactive Filters (Slicers)

## 🔍 Key Insights
- Basic plan customers show higher churn
- Low satisfaction users are more likely to leave
- Early-stage customers have higher churn risk
- Engagement (logins) strongly impacts retention

## 🛠 Tools Used
- Power BI
- DAX
- Data Visualization

## 📁 Files Included
- Churn Analysis dashboard.pbix
- customer_churn_dataset.csv

## 🚀 Conclusion
This dashboard helps businesses understand churn behavior and take proactive actions to improve customer retention.
